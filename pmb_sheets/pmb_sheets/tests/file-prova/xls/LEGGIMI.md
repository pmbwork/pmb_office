# File di prova dei .xls

- `prova.xls`, `prova.xlsx`, `prova-password.xls` (password «segreta»), `risultati-libreoffice.json`: creati da `crea-con-libreoffice.py` con LibreOffice
  (usato solo dall'esterno, come produttore di file di confronto).
- `irs-excel4.xls`: una tabella del «Data Book» 2001 dell'IRS (Internal Revenue Service, l'agenzia delle entrate degli Stati Uniti), scaricata da
  `https://www.irs.gov/pub/irs-soi/01db11ex.xls`; è nel formato di Excel 4.0 (un foglio senza contenitore, 99 formule). Le opere del governo
  federale degli Stati Uniti sono di pubblico dominio. `irs-excel4.xlsx` è lo stesso file convertito da LibreOffice, per il confronto.
